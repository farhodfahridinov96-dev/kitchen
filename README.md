# Таймлайн смены кухни — отдельное приложение

Обычный сайт без Claude и без серверов. Расписание лежит в одном файле `data.json`.
Сотрудники открывают ссылку, приложение само перечитывает расписание раз в 5 минут
и работает без интернета (показывает последнюю загруженную версию).
Менять расписание можете только вы: правки идут через личный ключ GitHub.

## Запуск (один раз, около 15 минут, бесплатно)

1. Зайдите на github.com и создайте аккаунт (если его нет).
2. Нажмите **New repository**. Имя, например, `kitchen`. Выберите **Public**. Нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file**. Откройте эту папку и перетащите в окно браузера **всё её содержимое**: `index.html`, `data.json`, `sw.js`, `manifest.webmanifest`, папки `icons` и `fonts` и остальные файлы. Внизу нажмите **Commit changes**.
4. **Settings → Pages**. В блоке *Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, папка **/ (root)** → **Save**. Через 1–2 минуты на этой же странице появится ссылка вида `https://ВАШ-ЛОГИН.github.io/kitchen/`. Это ссылка для сотрудников.
5. Ключ для правок: фото профиля → **Settings** (настройки аккаунта, не репозитория) → внизу **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Name: `kitchen`, Expiration: 1 year.
   - Repository access: **Only select repositories** → выберите `kitchen`.
   - Permissions → Repository permissions → **Contents: Read and write**.
   - Нажмите **Generate token** и сразу скопируйте ключ (покажут один раз).
6. Откройте ссылку из пункта 4, внизу страницы нажмите **Для руководителя**, вставьте ключ, нажмите **Войти**. Появятся кнопки правки.

Ключ нужен только вам и хранится только в вашем браузере. Сотрудникам его не давайте. Если ключ потерялся или попал не в те руки, удалите его на том же экране GitHub и выпустите новый.

## Как менять расписание

- Откройте ссылку, будучи вошедшим как руководитель. Нажмите на задачу, чтобы поменять время, название, описание. **＋ Задача** добавляет новую. Вкладка **Настройка** меняет ленты, вехи, заголовок. Вкладка **Правила** тоже редактируется.
- Правки видны только вам, пока вы не нажмёте **Опубликовать**. После этого файл `data.json` в репозитории обновляется, и у сотрудников расписание меняется в течение 5–7 минут (1–2 минуты GitHub обновляет сайт, затем приложение проверяет обновления раз в 5 минут).
- Кнопка **Как видят сотрудники** показывает страницу без кнопок правки.
- Если расписание успели поменять с другого устройства, приложение предупредит и предложит загрузить актуальную версию или опубликовать вашу поверх.

## Установка на телефон

Откройте ссылку в браузере → меню → **Добавить на главный экран** (на iPhone: Safari → «Поделиться» → «На экран Домой»). Значок «Кухня» откроется как обычное приложение.

## Не хочу GitHub

Подойдёт любой хостинг статических файлов (Netlify Drop, Cloudflare Pages, свой сайт): загрузите туда эту папку целиком. Правка: **Для руководителя → Править без GitHub**. Кнопка **Опубликовать** скачает новый `data.json`, замените им старый файл на хостинге. Сотрудники увидят изменения в течение 5 минут.

## Важно знать

- Репозиторий публичный, значит расписание видит любой, у кого есть ссылка. В поисковики страница не попадает (стоит запрет индексации), но секретной ссылка не является. Не вписывайте в задачи телефоны, пароли и личные данные.
- Если открыть `index.html` просто как файл (без хостинга), будет показан снимок расписания на день сборки, без автообновления.
- Сообщения при входе: «Ключ не подошёл» — ключ скопирован не целиком или просрочен; «нет права записи» — при создании ключа не выбрано **Contents: Read and write**; «не найден репозиторий» — неверно написано `логин/репозиторий` или ключ выдан на другой репозиторий.
- Через год ключ перестанет работать. Выпустите новый тем же способом и войдите заново.

## Что за файлы

`index.html` — само приложение. `data.json` — расписание (его и обновляют правки). `sw.js` и `manifest.webmanifest` — работа без интернета и установка на телефон. `icons/` — значки. `fonts/` — шрифт Onest (лицензия SIL OFL).
